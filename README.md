# 📊 HR Employee Attrition & Analytics Dashboard

An interactive, client-side web application designed to analyze HR workforce data, track employee attrition rates, evaluate exit reasons, and visualize key retention metrics. Built using **Tailwind CSS**, **Chart.js**, and **SheetJS**.

---

## ✨ Key Features
- **Executive KPI Summary Cards:** Instant view of Total Employees, Attrition Rate, Average Monthly Salary (PKR), and Work-Life Balance indices.
- **Interactive Multi-Filters:** Filter data instantly by Department, City, Gender, and Overtime status.
- **Dynamic Excel Integration:** Built-in SheetJS support allowing users to upload and visualize their own `.xlsx` datasets directly in the browser.
- **Rich Data Visualizations:** Powered by Chart.js (Department Attrition breakdown, Exit Reason Donut charts, Performance vs. Attrition, and Commute Distance impact lines).
- **Searchable Employee Directory:** Pagination and real-time search across employee records.
- **Sleek Dark Mode UI:** Modern slate-themed interface optimized for visual comfort.

---

## 🛠️ Tech Stack
- **HTML5 & Vanilla JavaScript (ES6+)**
- **Tailwind CSS** (via CDN)
- **Chart.js** (for interactive graphs)
- **SheetJS / XLSX** (for Excel file parsing)
